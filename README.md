# WINDPROOF

Three.js 製のブラウザー向け一人称 3D ミニゲームです。ライターやマッチを指先で操って火をつけ、左手で風やお邪魔から炎を守りながら、口元の煙草に火をつけるまでのタイムを競います。操作感は Hand Simulator のような「体の部位をそのまま動かす」不器用さをイメージしています。

PC（マウスとキーボード）でも、スマホ（横向き・タッチ）でも遊べます。

## 起動方法

Node.js 20.19 以降が必要です。

```bash
npm install
npm run dev
```

表示されたローカル URL をブラウザーで開いてください。

### スマホで遊ぶ

- 同じ Wi-Fi のスマホで試す：`npm run dev -- --host` で起動し、表示された `Network` の URL をスマホで開く
- Web で遊ぶ：<https://me1td0wn76.github.io/tabako/>（`main` に push すると、`.github/workflows/pages.yml` が自動で公開する）
- 別の所に置く：`npm run build` でできる `dist/` を、そのまま静的サイトとして公開する。相対パスで書き出すので、サブフォルダーに置いても動く
- PC でタッチ操作を確かめる：URL に `?touch` を付ける

## 難易度と場所

| 難易度 | 道具 | 場所 | 制限 |
| --- | --- | --- | --- |
| かんたん | ライター | ベランダ | なし |
| ふつう | 箱マッチ（10 本） | コンビニ前 | 60 秒。息が短い |
| むずかしい | 紙マッチ（8 本） | ビルの屋上 | 75 秒。息が短く、火がつくまで少し長い |
| 鬼 | ライター | 港の防波堤 | ガスが 12 秒ぶんだけ。強風。息が短い |
| 地獄 | 箱マッチ（5 本） | 温泉宿の縁側 | 58 秒。風向きが勝手に変わる。ヤスリが荒れている |
| 極 | 紙マッチ（4 本） | キャンプ場 | 80 秒。ゲージが見えない。折れやすい |
| チャレンジ（UNLIMITED） | 毎回変わる | 毎回変わる | 何本つけられるか。1 本ごとに厳しくなり、ストレスが MAX になったら終わり |
| おまけ（まったり喫煙） | ライター | 自分で選ぶ | かんたん・ふつう・むずかしいをクリアすると解放。時間もお邪魔もなく、ただ吸って吐く |
| 旅（ぶらり喫煙の旅） | その場で選ぶ | 歩いて探す | まったり喫煙で 3 本吸うと、外に出たくなって解放 |

まったり喫煙で選べる場所：ベランダ / コンビニ前 / ビルの屋上 / 純喫茶 / キャンプ場 / 港の防波堤 / 温泉宿の縁側

時間制限があるのはマッチだけです。ライターはタイムでランク（S〜D）が決まり、**60 秒を超えると F** です。マッチを使い切る・ガスが切れると失敗（F）になります。数字は `src/rules.js` にまとめてあります。

### ストレス

失敗（うまく擦れない・マッチを折る・落とす・火を消す・むせる など）と時間の経過で溜まり、MAX に近いほど手が震えます。火がつく・煙草を吸う・お邪魔をさばくと下がります。

## 遊び方

1. **拾う**：目の前の道具をクリック（タップ）で手に取る
2. **火をつける**：手元にズームした点火画面に切り替わる。握りが弱いとずり落ちて落とす
   - ライター：親指で奥のホイールを手前（右下）へ擦り下ろして熱を溜め、その勢いのまま手前の赤いレバーを押し込む
   - マッチ：**光っている所（着火場所）** だけを、SPEED の帯に入る速さで、短く擦る。1 回ごとに着火場所が変わる。速すぎる・全体をこする・何度も外すと、軸が傷んで折れる
   - 紙マッチ：左手で本体を持ち、右手のマッチで擦る。左手の力が抜けると本体を落とし、傾くとヤスリに当たらない。押しすぎるとすぐ折れる
3. **吸いつける**：一人称視点に戻る。炎を煙草の先端に当てて吸う。吸いすぎるとむせる。火が消えたら点火画面からやり直し

### まったり喫煙

左手の人差し指と中指で煙草を挟み、吸うときだけ口元へ運びます。離すと手で下ろして、煙を吐きます。灰が長くなると自分で灰皿へ落とし（手動でも落とせます）、吸い終えたらもみ消して吸い殻を灰皿に残し、次の 1 本に火をつけます。

### ぶらり喫煙の旅

一人称で歩き回り、**灰皿のある所**（全 16 か所）で一服します。火のつけ方（ライター・箱マッチ・紙マッチ）は、その場で選びます。

| 土地 | 行き方 | 喫煙所 |
| --- | --- | --- |
| 都会 | ここから始まる | 自宅のベランダ / コンビニ前 / 純喫茶 / 駅前 / 公園 / 路地裏の屋台 / ビルの屋上（エレベーター） |
| 湖のキャンプ場 | 風見駅前からバス | 焚き火の前 / 湖の桟橋 / 林のピクニック台 |
| 風見漁港 | 風見駅から電車 | 岸壁の釣り座 / 灯台の下 / 番屋の前 |
| 雪見の宿 | 風見駅から電車 | 旅館の縁側 / 足湯 / 門前の茶屋 |

土地は 1 つずつ開きます。着いた所のまわりだけ先に組み立て（その間は車窓の画面）、残りは歩いている間に裏で足していきます。ほかの土地の素材も、手が空いたときに少しずつ取っておきます。

## 操作

### PC

**点火画面（手元）**

| 入力 | 動き |
| --- | --- |
| マウス移動 | 親指の先（マッチは頭）を動かす |
| クリック長押し | 押し付ける |
| `A` `S` `D` `F` | 小指・薬指・中指・人差し指で握る（ライター・箱マッチ） |
| `Shift` 長押し / `W` `A` `S` `D` / `Q` `E` | 紙マッチだけ：左手で本体を持つ / 動かす / 傾きを直す |

**吸いつけ（一人称）**

| 入力 | 動き |
| --- | --- |
| マウス移動 | 右手（炎）を動かす |
| クリック長押し | ライターのガスレバーを押さえ続ける（離すと消える） |
| `W` `A` `S` `D` | 左手（風よけ）を動かす |
| `Q` / `E` | 左手首を回して、手のひらの向きを決める（炎の方を向いていないと風を防げない） |
| `Shift` 長押し | 左手をすぼめて炎を覆う（近づけすぎるとやけど） |
| `F` 長押し | 左手を水平にして煙草の上にかざす（雨よけ） |
| `Space` 長押し / 右クリック長押し | 煙草を吸う |
| `Esc` | 一時停止（止まっている間は `Q` でタイトルへ、クリック / `Enter` で再開） |
| `R` | タイトルへ戻る（プレイ中は長押し） |

**まったり喫煙**

| 入力 | 動き |
| --- | --- |
| `Space` / クリック長押し | 口元へ運んで吸う。離すと下ろして吐く |
| `F` | 灰皿に灰を落とす |

**ぶらり喫煙の旅**

| 入力 | 動き |
| --- | --- |
| `W` `A` `S` `D` / 矢印 | 歩く（`Shift` で走る） |
| マウス | 見まわす（画面をクリックすると固定。`Esc` で解除） |
| `E` / クリック | 一服する・扉を開ける・電車やバスに乗る |
| `M` | 地図と喫煙所の一覧 |
| `E`（吸っている間） | もみ消して立つ |
| `R` 長押し | 歩いている間はタイトルへ。点火の途中なら立ち上がる |

### スマホ

| 場面 | 操作 |
| --- | --- |
| 点火画面 | 左の「握る」を押さえたまま、右側をなぞる。ライターは指を置き直すと、親指がホイールの上へ戻る |
| 点火画面（紙マッチ） | 左のスティックに触れている間、左手で本体を持つ（倒すと動く。傾きは自動で戻る）。右側をなぞって擦る |
| 吸いつけ | 右側をなぞって炎を動かす（ライターは触れている間だけガスが出る）。左のスティックで左手、「すぼめる」「かざす」は押すたびに切り替え、「吸う」は長押し。手のひらは自動で炎を向く |
| まったり喫煙 | 画面を長押しで吸う。「灰を落とす」で灰皿へ |
| ぶらり喫煙の旅 | 左のスティックで歩く（いっぱいに倒すと走る）。右側をなぞって見まわす。出てきた案内をタップ |

## お邪魔イベント

- **突風**：予告された風上側へ左手を回し、手のひらを炎へ向けてすぼめる
- **蛾**：炎に寄ってくるので左手で払いのける
- **急な雨**：左手を水平にして、煙草の先の上にかざす
- **一本くれよおじさん**：横から手を出してくる。おじさん側で左手を左右に振って追い返す
- **ライター貸してくださいおじさん**：右手の道具へ手を伸ばしてくるので、右手を遠ざけて断る
- **くしゃみ**：連打してこらえる（点火画面でも起きる）
- **スマホ通知**：通知を左右にスワイプして全部消す（点火画面でも起きる）
- **着信**：スマホの「拒否」を押す（点火画面でも起きる）

## 素材の作り方

モデル・背景・質感・効果音は、ローカルの ComfyUI で作っています。プロンプトとシード、採用した番号は `tools/assetgen/` に残してあるので、同じ手順で作り直せます。

| 素材 | 使うもの | スクリプト |
| --- | --- | --- |
| 写真・背景 | FLUX.2 klein 4B | `gen.py photos` / `gen.py images`（中身は `specs.py`） |
| 3D モデル | TRELLIS.2（写真 → GLB） | `gen.py mesh --only 名前` |
| 手のリギング | Blender 4.5 | `bl_hand.py`（ゲームの手の寸法へ変形して骨を入れる） |
| 人物のリギング | Blender 4.5 | `bl_people.py`（頭・両腕・口の動き） |
| 小物の整形 | Blender 4.5 | `bl_props.py`（当たり判定と同じ寸法へ合わせる。ライターのフード・ホイール・レバーはここで組む） |
| 場所に置く物 | FLUX.2 → TRELLIS.2 → Blender | `run_scene.sh` → `bl_scene.py`（中身は `scene_specs.py`） |
| 画像の仕上げ | Pillow | `prep_images.py` |
| 効果音・環境音 | Stable Audio 3 small SFX | `sfx.py gen` → `sfx.py build` |
| 公開用に軽くする | glTF Transform / sharp | `compress.mjs`（モデルは meshopt と WebP、画像は WebP。作り直したら最後にかける） |

ComfyUI（`127.0.0.1:8188`）を起動してから、ComfyUI の Python で実行します。途中の写真や GLB は `ComfyUI/output/tabako/` に残ります。

```bash
cd tools/assetgen
C:/Users/user/ComfyUI/.venv/Scripts/python.exe gen.py photos --only lighter_body
C:/Users/user/ComfyUI/.venv/Scripts/python.exe gen.py mesh --only lighter_body --faces 8000 --tex 1024
"C:/Program Files/Blender Foundation/Blender 4.5/blender.exe" -b -P bl_props.py -- C:/Users/user/ComfyUI/output/tabako/glb ../../src/assets/models lighter
```
